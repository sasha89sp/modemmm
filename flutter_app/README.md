# Huawei E173 Portable Manager v2.0.0 (Windows Flutter)

Портативная программа для Windows x64 на Flutter с нативным Win32 FFI драйвером COM-портов (`kernel32.dll`), звуковым движком (`winmm.dll`), локальной базой SQLite и экспортом Excel.

## Основные возможности

1. **Подключение и адаптивный мониторинг**:
   - Автопоиск COM-портов Windows с PnP-метаданными (приоритет `PC UI Interface` / `Modem`, сохранение предпочтительного порта и `baud`).
   - USB Hotplug: мгновенное освобождение порта при извлечении модема и автоподключение при возврате.
   - Информация о модеме и сети: модель, IMEI, прошивка, оператор, статус регистрации, сигнал (% и dBm), состояние SIM.
   - Эконом-режим `SIM не обнаружена` (опрос SIM раз в 60 сек, отключение запросов к сети/SMS/автосценариям) и снижение нагрузки при простое и сворачивании окна.
2. **Конструктор и движок сценариев**:
   - Шаги: определение номера по USSD (с раздельным разбором номера/баланса и кэшированием в прогоне), произвольный USSD, проверка баланса с ожиданием входящего SMS, отправка SMS с проверкой порога баланса, пауза, голосовой вызов с действиями по секундам (фраза WAV / DTMF), отправка DTMF.
   - Добавление, редактирование, дублирование, перетаскивание, удаление, остановка/продолжение при ошибке, автозапуск по оператору (1 раз за сессию).
3. **Экспорт и настройка таблицы Excel**:
   - Единый файл `UserData/Excel/scenario_results.xlsx` (лист `Результаты`), пересборка из SQLite задним числом, сверка первого и последнего баланса (`СОВПАЛ` / `НЕ СОВПАЛ` с подсветкой), выбор/порядок/заголовки колонок, пресеты и автоматическая резервная копия при блокировке файла.
4. **SMS и звуковое оповещение**:
   - PDU-декодер (`AT+CMGF=0`, `AT+CMGL=4`), UCS-2, склейка составных SMS (UDH), папки «Входящие» / «Отправленные» / «Корзина», счётчик непрочитанных, надгробия при удалении навсегда, групповые действия, диагностика (`AT+CNMI?`, `AT+CPMS?`, `+CMTI`) и мелодия `winmm.dll` с громкостью и проверкой.
5. **Звонки и голосовые фразы**:
   - `ATD` / `ATA` / `ATH` / `AT+VTS` / `AT+CLCC`, аудиомост по отдельному звуковому COM-порту (`AT^DDSETEX=2`) через `winmm.dll` с отключением микрофона/динамиков и счётчиками байт, библиотека фраз `UserData/Sounds` (запись, импорт WAV, предпрослушивание, воспроизведение в звонок).
6. **USSD, контакты SIM, AT-терминал и журналы**:
   - USSD с DCS `15` / `72`, сохранённые команды, пакетный запуск; контакты SIM (`AT+CPBR`/`AT+CPBW`); AT-терминал; журналы SQLite, экспорт CSV и диагностика циклов `DIAG`.
7. **Портативность и системный трей**:
   - Все данные хранятся в `UserData` рядом с `.exe`; сворачивание в трей при закрытии, иконка окна/панели задач/трея, история версий в настройках.

## Сборка через GitHub Actions

При каждом пуше в `main` запускается workflow `.github/workflows/build-windows-portable.yml`, который собирает портативный архив `huawei_e173_manager-v2.0.0-portable-win64.zip` в разделе **Actions → Artifacts**.
